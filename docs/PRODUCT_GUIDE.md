# 产品体验与验收指南

## 先看这条闭环，不要先数功能

打开首页时，星图以「一般过去时」为中心，右侧是它的真实课文出处。首次提示只保留三个动作：选一课、读懂它、留下有用的表达。你不需要先理解所有入口。

推荐使用第二册第一课 **A private conversation** 检查整条路径。这一课源文较短，能同时验证叙事时态、进行时、语块和复习回溯。

| 你要验证的问题 | 操作 | 应该看到什么 |
| --- | --- | --- |
| 我知道从哪开始吗？ | 首页打开推荐课文 | 先出现课文画像、场景与知识胶囊，不直接堆出所有工具 |
| 能否完整读一篇？ | 点开始精读 | 全文按句显示；编号不挡正文；移动端只有一栏 |
| 注解是否与原句有关？ | 点第 6 句 | 句详情显示 `They were talking loudly.`，而非泛泛的课程介绍 |
| 知识点能否定位？ | 左侧点「一般过去时」 | 定位与高亮所有真实命中句；可跳到下一处出现位置 |
| 高亮会不会淹没原文？ | 展开阅读层 | 默认范句、语法、语块与体裁打开；词、衔接可自行打开 |
| 学习状态是否统一？ | 给句子星标，再保存一个知识点 | 两者进入同一张卡片库；重复保存不新增副本 |
| 保存有没有实际作用？ | 打开我的卡片 | 到期数、来源、状态来自真实保存；没有预置虚假打卡记录 |
| 复习能否回到语境？ | 翻面，点出处 | 回到精确句子或知识点命中位置，保留返回复习按钮 |
| 中途离开会不会丢失？ | 复习中暂时离开，再继续 | 保留队列、当前卡和是否已翻面；已评分卡不重做 |
| 评分是否改变调度？ | 选择记得，再查看卡片库 | reps、稳定度、难度、下次到期与日志一起更新 |
| 控制权是否在用户？ | 暂停、恢复、重置或删除卡片 | 暂停不删除；重置保留原始保存时刻；删除需要确认 |

## 各入口只承担一个问题

**知识星图**：某个表达和谁相关？只画一小片邻域。实线为组成 / 从属 / 出处，虚线为同课共现，不把共现冒充语义相似。手机以分组列表替代图形计算。

**知识索引**：这里有哪些内容？词、语块、句型、语法、课文和三类句子都能检索。知识点支持关联度、出现课数、名称、类型排序；课文仍按册课序排列。

**连学**：我想表达什么？25 条 can-do 路径按生存 → 日常 → 叙事 → 读写 → 思辨组织，各阶段内以覆盖课文数排序；这是对 SPEC 中“数量降序”与“逻辑顺序”两项要求的折中。卡片点开先看画像，再读正文。

**课文共点**：哪些课文可以一起读？展示实际共享知识点最多的 100 对。除了数字，还把共享表达列出来；pill 和两侧课文均能点击。

**阅读工作台**：这一课到底怎么读？左栏定位，正文阅读，右栏解释。平板把右栏放进底部抽屉；手机知识胶囊收起，详情变成全屏 sheet，关闭后继续原句。

**我的卡片 / 复习**：值得留下的表达什么时候再看？没有独立卡组和重新整理题目的负担，来源实体本身就是卡片。手机复习时隐藏底部多功能导航，把翻面与四档评分固定在底部。

## 三个设备尺寸

PC 1280×800：正文、左胶囊、右句详情应同时可见。Pad 768×1024：正文和胶囊并排，点句子打开抽屉；星图可以平移和缩放。Phone 375×667：可以从第一句一路滚动到最后一句，点击编号看句详情，再点“回到这一句”关闭详情并精确定位；复习评分按钮不小于 60px。

本项目对这些尺寸完成的是 Chromium 仪器化模拟检查，不等同于在真实 iPhone / iPad Safari 上逐台验收。

## 看哪些文件可以理解改动

`src/pages/Reader.tsx` 是主流程落点；`components/Details.tsx` 把各入口连回同一份上下文；`lib/store.tsx` 统一星标、卡片和复习写入；`lib/fsrs.ts` 负责调度；`lib/highlight.ts` 负责重叠高亮切分；`scripts/knowledge.mjs` 和 `editorial.mjs` 决定内容如何组织。

不要把工作台的颜色命中看成语言学证明。真正检查注解质量时，应对照原文、规则与 `docs/DATA_QUALITY.md`，尤其注意截断首句、专名、过去分词和叙事语气等边界情况。
