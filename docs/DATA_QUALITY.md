# 数据质量与来源边界

## 不把课文缺口悄悄补成“原文”

原始四册 Markdown 和产品 SPEC 原样保留在 `sources/`。第一册 72 篇奇数主课，第二册 96 篇，第三册 60 篇，第四册按附件实际收录的 60 篇处理，总共 288 篇。第四册附件自己说明与 48 课版本的差异，因此本项目不把它改造成另一个教材版本。

第四册两个 Lesson 27 都保留，分别是源文件内第 26、27 篇。部分第一 / 第三册标题与正文首句粘连，部分首句或标题被截断，另有拼写、标点、数字和历史事实疑点。这些不通过模型补写来掩盖。解析器只拆分有明确规则的可见内容；原始标题、原始正文和来源位置都保留。第四册用中文阅读主题作为展示标题，明确标记为整理主题，不冒充原版英文标题。

`data-audit.json` 列出 168 个源格式问题记录。该数字不是源文所有拼写、语法、版本和事实问题的总数；并没有完成权威版本逐句校对。

## 三层内容来源

1. **原文**：用户给出的 Markdown 可见文本，保存真实位置。
2. **原有旁注**：源文里已有的中文注解，保留在语境中并标记 provenance。
3. **整理内容**：中文词义、语块释义、语法提示、句型模板、能力路径、阅读主题和部分摘要；这些是本项目生成与人工规则整理的内容，不是出版社原注。

页面以阅读为主，不常驻大段工程说明；来源与规则提示放在详情及“原文与收录说明”的折叠区。没有足够材料的词不编出中文定义，而是用原句解释其存在。

## 统计口径

8,088 个索引条目包括：7,741 词形、275 语块、32 句型、40 语法。词形没有全部合并为 lemma，因此 be / was / were、单复数等可能占不同条目。不能用这个数字宣称学习者需要掌握 8,088 个独立词汇或本项目拥有 8,088 份人工精校注释。

3,573 个词形获得原文旁注或词表映射的整理释义，4,168 个仅提供语境。专有名词、罕见词和源文拼写问题可能进入后者。词形映射属于保守规则，仍有可能选到不符合当前多义词语境的义项。

4,606 句是阅读用句段，包括极短对话、引语片段、源文件拆开的缩写和残句。不是经过人工修复的标准句法句数。范句 415、长难句 401、例句 3,790，是规则分档后的实际数量，不硬凑 SPEC 的近似数。

## 注解能力与限制

语块来自明确的表达词表和有限词形变化匹配；句型来自有限模板；语法点由正则和局部排除规则产生。已经排除了部分“left = 左侧”被误认成过去时、过去分词被当成简单过去时等问题，但**没有运行依存句法分析或逐句人工语法核验**。

右侧的“从句线索”是基于连接线索的近似数，不是严格从句数量。范句 / 长难句是阅读提示，不代表其他句子没有学习价值。共现边只说明在同一课里出现，不代表同义、反义或因果。

能力路径由主题与课程画像整理，每课至少进入一个路径。它帮助选课，不是经过用户实验验证的能力测评。非重点课的内容预览以原文摘录为主，不伪造一份“教材标准摘要”。

## 已验证的是可追溯性，不是内容完美

`npm run data:check` 验证所有 4,606 个句段都能从其 sourceBlock + sourceStart 精确还原；44,452 个命中位置合法，正反关联一致；288 个课文 ID 不冲突；25 路径非空；100 课文对的共点数等于真实交集；四个文件 SHA-256 对应原附件；40 份 gzip 与 JSON 内容一致。

这 212,612 项结构断言不能代替语言教学专家校订。公开发布前应优先处理源文残缺和版本混杂，再抽查语法识别、词义语境、能力归属。原文中的医学、法律、科学、历史或社会观点只作为语言学习材料，不能当作当前事实或建议。
